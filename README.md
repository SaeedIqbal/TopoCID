# TopoCID: Topological Causal Invariance and Structure-Preserving Counterfactuals for Graph OOD Generalization

---

## 📖 Problem Formulation

Graph Neural Networks (GNNs) suffer severe performance degradation under Out-of-Distribution (OOD) shifts due to overfitting spurious environmental shortcuts. We formalize this using a Structural Causal Model (SCM) $\mathcal{M}_{SCM} = \langle \mathcal{S}, \mathcal{U}, \mathcal{F}, P(\mathcal{U}) \rangle$, where the input graph $G$ is generated by a causal core $G_c$ and an environmental shortcut $G_s$:

$$ G_c = f_c(G, U_c), \quad G_s = f_s(G, U_s), \quad Y = f_y(G_c, G_s, U_y) $$

The variable $G_s$ acts as a confounder, creating a backdoor path $G_c \leftarrow G \rightarrow G_s \rightarrow Y$. To isolate the true causal effect, we must compute the interventional distribution via backdoor adjustment:

$$ P(Y \mid do(G_c)) = \int_{G_s} P(Y \mid G_c, G_s) dP(G_s) $$

Our objective is to learn a topological projection $\Phi$ and classifier $f_\phi$ such that the representation $Z_{topo} = \Phi(G)$ satisfies the conditional independence criterion $Y \perp E \mid Z_{topo}$, strictly remaining on the valid data manifold $\mathcal{M}$.

---

## 🔍 Research Gaps: The Subgraph Fallacy

Existing graph OOD generalization methods are fundamentally constrained by two critical mathematical and structural deficiencies:

1. **The Locality Fallacy**: Subgraph rationalization methods (e.g., CAL, CIGA, DIR, GSAT, PISA) rely on local edge/node masking ($G_{masked} = G \odot \alpha$). This destructive process severs critical message-passing pathways and destroys global topological invariants (e.g., persistent homology, Betti-1 cycles, spectral signatures) that frequently dictate true causality in complex systems.
2. **The Intervention Fallacy**: Counterfactual methods attempting latent feature mixing (e.g., GCCDL's $h_{mix} = h_{G_c}^i + h_{G_s}^j$) operate in unconstrained latent spaces. Because the valid data space forms a highly non-linear manifold $\mathcal{M}$, linear addition almost surely yields representations outside $\mathcal{M}$ ($h_{mix} \notin \mathcal{M}$), generating structurally invalid "Frankenstein" graphs that violate physical constraints (e.g., chemical valency).

---

## 💡 Proposed Methodology & Workflow

TopoCID abandons subgraph masking and unconstrained latent mixing, introducing three synergistic modules:

### 1. Differentiable Topological Causal Projection (TCP)
Extracts global, mathematically stable topological invariants via persistent homology, bypassing locality constraints.

$$ Z_{topo}^{(k)} = \Psi_k(\text{Dgm}_k(G)) = \sum_{(b, p) \in \text{Dgm}_k} f_\phi(p) \cdot \kappa_\theta(b, p) $$

where $f_\phi(p)$ is a learnable polynomial gating function that suppresses transient environmental noise ($p \leq \epsilon$).

### 2. Structure-Preserving Counterfactual Generation (SPCG)
Generates valid counterfactuals via a manifold-constrained reverse Stochastic Differential Equation (SDE). The orthogonal projection matrix $\Pi_{\mathcal{M}}$ strictly confines the trajectory to the tangent space of $\mathcal{M}$:

$$ \Pi_{\mathcal{M}} = I - J_C^\top (J_C J_C^\top + \delta I)^{-1} J_C $$

This mathematically guarantees a **100% Structural Validity Rate (SVR)**.

### 3. Topological Contrastive Disentanglement (TCD)
Explicitly minimizes the mutual information $I(Z_{topo}; Z_{env})$ using the CLUB variational bound and InfoNCE contrastive learning to enforce $Y \perp E \mid Z_{topo}$.

## 📏 Evaluation Metrics


1. **OOD Generalization Gap ($\Delta_{OOD}$)**: $\Delta_{OOD} = \mathbb{E}_{e \in \mathcal{E}_{train}}[\mathcal{R}_e] - \mathbb{E}_{e' \in \mathcal{E}_{test}}[\mathcal{R}_{e'}]$, where $\mathcal{R}_e = 1 - \text{Metric}_e$. Lower is better.
2. **Causal Motif Precision/Recall**: Evaluated on MUTAG using ground-truth masks $M_{gt}$ (e.g., $-\text{NO}_2$) vs extracted topological masks $M_{topo}$ ($p_i > \tau_{opt}$).
3. **Structural Validity Rate (SVR)**: $\text{SVR} = \frac{1}{N_{cf}} \sum_{k=1}^{N_{cf}} \mathbb{I}[C(G_{cf}^{(k)}) = 1]$, verifying chemical valency constraints.
4. **Mutual Information (MI)**: Estimated post-training using the CLUB upper bound $\hat{I}_{CLUB}$ to verify statistical independence between $Z_{topo}$ and $Z_{env}$.

Ensure your datasets are placed in the root directory:
